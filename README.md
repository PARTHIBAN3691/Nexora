# Nexora Technologies — React Website

A responsive corporate website built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Before launch

1. Replace `Nexora Technologies` with the final company name.
2. Replace the placeholder email, phone and Chennai address.
3. Connect the enquiry form in `src/main.jsx` to your backend, CRM or email service.
4. Replace the temporary capability/industry content with the actual services offered.
5. Add a real logo/favicon and social/SEO metadata.

The site currently uses Google Fonts from the web. If you need a fully self-contained deployment, bundle the fonts locally.
